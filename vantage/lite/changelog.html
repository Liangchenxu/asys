0.23.0

最新
  • 标签音频提示：正在播放声音或已静音的标签显示喇叭图标，点击图标即可切换静音；标签右键菜单也提供「静音标签页 / 取消静音」。
  • 固定标签页：右键菜单可固定标签，固定后移到标签条左侧，恢复会话时保留。
  • 全屏：F11 进入或退出全屏；网页视频全屏时自动隐藏标题栏、地址栏和书签栏。
  • 标签操作开关：双击关闭、中键关闭、允许固定标签，三个开关独立控制。
  • 新标签页布局：logo 与搜索框整体垂直居中，搜索框加宽并随窗口收窄。
  • 细节修复：标签右键菜单恢复原生宽度；播放音频时顶部指示条不再被喇叭按钮遮挡；喇叭图标改用强调色。

0.22.1

  • 新标签页布局：logo 与搜索框整体垂直居中，不再贴着页面顶部；搜索框加宽到 1000px 上限，窗口变小时跟随收窄。

0.22.0

  • 下载项增强：下载面板与下载管理页支持复制下载链接、打开来源页、删除磁盘文件（与删除记录分开）。
  • 完成角标：下载完成后工具栏下载按钮显示小圆点，打开下载面板后清除。
  • 还原按钮：工具栏右侧新增「重新打开关闭的标签页」按钮，与 Ctrl+Shift+T 等效。
  • 问题修复：修复页面焦点下 Ctrl+Shift+T 被 WebView2 吞掉；修复活动标签顶部指示条未覆盖关闭按钮区域；下载管理页图标提示改为主题化浮层。

0.21.0

  • 历史按日期分组：分为「今天 / 昨天 / 更早」，与时间范围筛选、关键词搜索联动，空分组自动隐藏。

0.20.0

  • 书签网址编辑：书签管理器与书签栏右键可直接修改网址。
  • 网址规范化：省略协议自动补 https://，支持 http / https / ftp / file / mailto。
  • 校验：拒绝无效协议与重复网址，标题原本等于旧网址时同步更新。

0.19.2

  • 书签导入归类：浏览器书签栏内容并入「书签工具栏」，其他书签并入「其他书签」，移动设备书签保留为文件夹。
  • HTML 导入：识别 Firefox 的 PERSONAL_TOOLBAR_FOLDER 和常见书签栏名称，不再生成额外的日期文件夹。
  • 合并与去重：同名文件夹递归合并，URL 按忽略大小写去重。

0.19.1

  • 标签顶部点击：修复活动标签顶部指示线拦截鼠标点击的问题。
  • 设置板块重排：按使用频率调整顺序。
  • 菜单尺寸：原生弹出菜单固定宽度、限制最大高度，超长文字省略并支持滚动。

0.19.0

  • 从已安装浏览器导入书签：支持 Chrome、Edge、Brave、Vivaldi、Chromium、Yandex、QQ 浏览器、360 极速、Opera、Opera GX、Firefox、Vantage、LibreWolf、Waterfox，可多选。
  • HTML / .url 导入：支持 Netscape HTML 书签和 Windows 快捷方式文件。
  • 设置入口：设置 → 书签 → 导入书签。

0.18.0

  • 隐私浏览工作区：InPrivate Profile，不写历史、会话和下载记录，退出时清理并恢复普通工作区。
  • 隐私模式内存回收：停留 5 分钟后回收普通工作区空闲标签。
  • 隐私模式外观：Vantage 蓝绿配色、提示条与隐私新标签页。
  • 标签增强：标签右键菜单、拖拽排序、Ctrl+Shift+T 重新打开关闭的标签。
  • 默认不恢复上次标签页：新配置默认关闭，已有配置保持原值。

0.16.3

  • 地址栏显示 HTTPS / HTTP 锁图标。
  • 无协议域名自动补全，HTTPS 失败时尝试 www 和 HTTP，证书错误不降级。
  • 修复标题栏最顶部 5px 拖动区域吞掉标签点击的问题。
