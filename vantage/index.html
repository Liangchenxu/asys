什么是 Vantage?

Vantage 是 Firefox 的独立定制版本，其主要目标是隐私、安全和用户自由。由 ASYS 科技维护并针对现代环境进行深度优化。

🚫

无遥测

没有实验、广告、干扰或不必要的骚扰。

🔍

准确快速的搜索

默认使用Microsoft Bing搜索引擎，也可以自由更换为百度、谷歌、Duckduckgo等引擎。

🛡️

内置内容拦截

默认包含强大的拦截功能，提升浏览纯净度。

🔒

增强隐私

进行硬核加固以最大化隐私保护。

🔄

跨端同步

支持Mozilla账号登录，无缝衔接你在其他Firefox内核浏览器和设备上的配置数据，包括主题、扩展、书签和其他配置。

🔓

开源透明

代码完全公开透明，任何人都可以参与开发。

Vantage 与 Librewolf 或 Mozilla 无关。
