更新日志 (Changelog)

v150.0.2-1 最新版本

✨ 更新日志：

  • 升级至 Firefox 150.0.2，同步 LibreWolf 上游安全更新和补丁。
  • 新增 Windows 安装程序 Publisher 名称，现在显示为 Vantage 而非 Mozilla。
  • 新增 Windows 安装器中文化，安装程序界面现在会优先显示简体中文，并在卸载时询问是否删除配置文件。
  • 更新检查改进：移除 24 小时时间限制，改为每次启动时检查更新，并新增自定义更新服务器地址支持。
  • 修复设置面板复选框同步问题：IPv6 开关、WebGL 开关、同步开关等单选项现在可以正确保存配置到 about:config。
  • 恢复 about:debugging 按钮到设置面板。
  • 截图工具将扩展默认固定到工具栏。
  • 新增默认图标尺寸：22x22、24x24、256x256 像素图标 (这几个尺寸的依然使用Librewolf，暂未修改)。
  • 新增 Linux ARM64 打包支持，包括 deb、rpm、AppImage、portable tar.gz。
  • 安全增强 (来自 LibreWolf 150.0-1):
    • 防止通过 branding 进行浏览器指纹识别
    • HTTPS 自动升级增强，自动升级本地连接
    • DoH 查询改为 POST 方法 (隐私更好)
    • 禁用 OCSP (减少隐私泄露，已有 CRLite 补偿)
    • 禁用企业根证书 (防止中间人攻击)
    • 禁用 HTTP3 0-RTT (防止重放攻击)
    • 禁用弱加密套件

如果觉得好用，麻烦点个star吧！

v149.0-3

是的，这是另一个重要更新

Windows用户注意新版数据存储位置已经变更，请使用下面的migrate.bat来迁移旧版数据！

✨ 更新日志：

  • 新增 AI 侧边栏功能（默认关闭），集成 DeepSeek、通义千问、豆包、ChatGPT、Gemini、Claude 等 AI 服务，可在设置中一键开启。
  • 新增隐私仪表盘（about:protections），重新设计保护状态页面，支持中英文，隐私设置页新增快捷入口按钮。
  • 支持分屏浏览（Split View），右键标签页即可使用，继承自 Firefox 149 原生功能。
  • 新增 macOS x86_64 交叉编译支持，首次成功产出 DMG 安装包，可通过 Rosetta 2 在 Apple Silicon 上运行。
  • 新增 macOS ARM64 及 Linux ARM64 编译配置（mozconfig）。
  • 新增卸载器改进：移除 Mozilla 卸载调查问卷，卸载完成后询问是否清理用户数据。
  • 新增安装器中文化 patch，优先加载中文 locale 资源。
  • 打包系统新增多架构支持。
  • RPM 打包启用多线程压缩（xzmt），提升打包速度。
  • 更新 .gitignore，排除 .deb/.rpm/.AppImage 等构建产物，清理 git 历史中误提交的大文件（仓库体积从 499MB 缩减至 12MB）。
  • DMG 打包修复：自动检测并设置 Mach-O 可执行文件权限，解决安装后无法运行的问题。
  • macOS SDK 版本要求放宽至 26.1（原 26.2）。
  • Windows安装程序显示语言改为简体中文，用户现在可以在卸载时决定是否删除配置文件了。
  • Windows用户注意新版数据存储位置已经变更，请使用下面的migrate.bat来迁移旧版数据！

⚠️ 已知问题：

  • macOS用户注意：Vantage浏览器的macOS版尚未签名，这可能导致在Apple Sellicon的mac设备上无法正常运行。如果你有能力，可以帮助我们签名
  • Windows用户注意：Vantage浏览器的Windows版尚未签名，如果你有能力，可以帮助我们签名

有任何问题都请提Issue或者PR！一定会看！

v149.0.-2

🚨 重要更新，请所有vantage旧版用户尽快升级！

✨ 更新日志：

  • 补全 WebGL 权限相关翻译。
  • 将 Vantage 的配置文件夹迁移，不再和 Librewolf 共享目录。
  • 现在开始的一段时间内，Windows版安装程序将会集成配置文件迁移功能。
  • 添加了默认浏览器检测，现在可以在浏览器设置里面查看当前是否是默认浏览器了。
  • 修复设置中的配置项说明链接，现在这些配置项指向 Mozilla 的页面。
  • 修复 Windows 主题加载问题。
  • 繁体中文已经重新启用并可用。
  • 重新配置更新检查，后台每 24 小时检查一次更新，支持忽略特定版本，检查到更新后将提醒。
  • 设置面板新增“更新”区块 —— 可手动启用/禁用更新检查，“关于”页面的手动检查更新依然保留。
  • 移除打包目标对 package 的冗余依赖，加速重复打包流程。

⚠️ 已知问题：

  • NSIS 安装器语言 —— 强制中文的 patch 未生效，安装器界面仍为英文。
  • 卸载残留 —— 卸载器保留用户 profile 目录（Firefox 行业惯例）如果使用geek卸载，则可以彻底清除。
  • 设置中依然有少量文本为繁体中文。

任何bug反馈或者新的需求和建议都可以提Issue或者PR

v149.0-1

✨ 更新内容：

  • 合并上游补丁，更新版本号到 149.0
  • 修复增强型跟踪保护的 bug，现在将会默认启用严格保护，并修复严重网站问题

v148.0.2-2

✨ 更新日志：

  • 合并上游补丁
  • 增加更新检查功能，由用户自己决定是否更新

⚠️ 已知问题 - 广告拦截插件丢失：

  • Ublock Origin广告拦截在中国大陆地区可能未能自动下载到浏览器中，此问题源自Mozilla不被中国的广告商允许向中国大陆提供此类广告拦截插件，因此无法解决。
  • 在中国大陆的用户需要手动下载，前往 Ublock Origin的仓库 下载正式版的XPI文件然后拖到浏览器里面就可以安装了（文件末尾带有 signed 的标记的就是正式版）。
