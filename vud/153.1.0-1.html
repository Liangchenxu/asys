v153.1.0-1

新功能

  • 「恢复最近关闭」按钮 — 工具栏新增恢复按钮，一键恢复最近关闭的标签页或窗口，无需记忆快捷键
  • 默认开启 DoH（国内优化） — 内置阿里 AliDNS、腾讯 DNSPod 国内加密 DNS，默认使用阿里，DNS 故障时自动回退系统 DNS，内网/VPN 场景不断网
  • Linux 标签休眠 — 内存不足时自动休眠不活跃标签页，释放内存

预装扩展调整

  • 修复预装插件失效问题 — 修复新版浏览器预装插件（uBlock Origin 等）无法自动安装的问题
  • 移除失效扩展 — 移除 Absolute Enable Right Click & Copy 与 SessionsRestore (签名已被 Mozilla 吊销)；右键解除改用 Allow Right-Click 替代，会话恢复使用工具栏「恢复最近关闭」按钮或 Ctrl+Shift+T/N
  • 清理不再维护的扩展 — Tampermonkey 与截图扩展停止预装，已安装的将自动卸载

Windows 安装器

  • 多语言安装器 — 安装程序自动匹配系统语言 (英文/简体中文/繁体中文)
  • 更新下载更稳定 — 放宽自动更新 (WinUpdater) 的下载超时限制

语言

  • 巨硬中文翻译修正 — 剔除词典词形注释污染 (如「XX的复数形式」类释义)，翻译更干净自然
  • 英文变体补全 — 新增 en-GB/en-CA 完整语言支持

发布

  • winget 上架 — Windows 用户可通过 winget 命令直接安装/升级 Vantage
