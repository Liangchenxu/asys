v153.4.0-1 最新版本

内核升级：Firefox ESR 153.3 -> ESR 153.4（含 2026-09 安全修复，见 MFSA 2026-100）。
消化不良的时候吃点多酶片还是有效的

新功能

  • 新增 macOS 版本（未签名） — macOS（x64 / arm64）安装包无法直接运行：未签名、未公证，会被系统拦截，需手动解除隔离后方可使用（见「关于代码签名」文档）
  • 查找栏改为右上角悬浮 — 采用 Chrome 风格的右上角悬浮面板，搜索选项收进可折叠行，结果计数改为简洁的「x/y」（设置 → 浏览器行为 可开关）
  • 右键「在 IE 中打开」(Windows) — 在页面或标签页上右键即可用 IE 打开
  • 多线程下载开关进工具栏 — 可在「自定义工具栏」把开关拖到工具栏，随时切换
  • 多线程下载更省心 — 临时分片改存到系统缓存目录，不再散落在下载文件旁；最小分段大小可自行填写

设置与隐私

  • 风险操作先弹窗确认 — 关闭或削弱安全保护前会弹出确认，避免误触

修复

  • 语言不再固定为中文，默认跟随系统 — 设置里改语言后也不再被还原
  • 修复「限制字体可见性」开关无效
  • 修复「修复严重网站问题」被关闭后无法开启、部分站点打不开
  • 修复 Linux 上部分视频无法播放 — 补齐 H.264 解码依赖（deb / rpm 安装包）
  • 修复多线程下载同名文件互相覆盖 — 不同目录下的同名文件不再互相干扰

发布

  • 内核升级 Firefox ESR 153.4 — 修复多项高危安全漏洞（详见 Mozilla 安全公告 MFSA 2026-100）
