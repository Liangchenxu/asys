Vantage 153.0-5 更新日志

新功能

  • 配置备份与恢复 — about:preferences#vantage 新增“配置备份与恢复”分区，支持导出完整浏览器配置（书签、历史、扩展、设置、工具栏布局）为 ZIP 压缩包，或从备份一键恢复，恢复后自动重启生效
  • 导出安全提醒 — 导出前提示备份包含 Cookie、浏览历史等敏感数据；登录密码库 (logins.db) 默认排除，防止备份泄露导致密码外泄
  • 恢复安全网 — 恢复前自动生成时间戳备份可随时回退；校验备份结构并拦截路径穿透攻击；自动排除 cache2/storage 等缓存目录

Nova 外观

  • Nova 新界面默认开启 — 移植 Firefox 155 的 Nova 新外观 (圆润标签、浮动工具栏)，Vantage 蓝绿渐变标题栏，含深色模式适配，设置页可切换，即时生效无需重启
  • 配色全面修复 — Nova 默认 violet 调色板替换为 Vantage 蓝，标签渐变、隐私窗口边框、smartbar 渐变、菜单分隔线等 9 处细节

Windows 自动更新 (WinUpdater) 重构

  • 独立安装页 — WinUpdater 改为可选组件，安装时独立“自动更新”页 (默认勾选)，可在 Windows 设置→应用 中一键卸载
  • 完整卸载清理 — 卸载时彻底移除计划任务、AppData 副本、注册表项与组件目录
  • 防自杀保护 — 静默全新安装 (/S) 不装 WinUpdater；静默升级保留已装组件
  • 构建修复 — 修复多平台共享构建目录时 Windows 组件污染 Linux/macOS 包的问题
