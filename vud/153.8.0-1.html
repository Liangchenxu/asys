v153.8.0-1 最新版本

内核升级：Firefox ESR 153.7 -> ESR 153.8（含 2026-11 安全修复，见 MFSA 2026-133）。
本软件由 蓝色大肥鱼 提供开发支持

新功能

  • 网站兼容 — 地址栏新增「网站兼容」按钮，可为当前站点伪装成 Chromium；再次点击恢复
    • 右键菜单新增「在 Chromium 浏览器中打开」，支持页面、链接和标签页；装有多个浏览器时以子菜单选择

改进

  • 任务栏标签页 — 地址栏的「添加到任务栏」按钮默认关闭，可在 设置 -> Vantage -> 标签页 开启（Windows）
  • 密码框不安全提示 — 默认只在公网 HTTP 页面提示；内网页面（含 IP 与本地主机名）不再提示，可在 设置 -> Vantage -> 隐私 恢复
  • 自动更新不再打扰 — 检查、下载、安装和更新完成都不再弹出提示，仅在出错时提示；同一版本不会反复提示或重复下载；手动检查时以托盘图标显示进度

修复

  • 旧发行版无法安装 RPM 包 — 过滤 libonnxruntime 的 GLIBCXX_3.4.30 自动依赖
  • 设置页分组重复显示 — 「密码」和「默认搜索引擎」不再重复出现

发布

  • 内核升级 Firefox ESR 153.8 — 修复安全漏洞（详见 MFSA 2026-133）
  • macOS 版本尚未签名 — 安装包无法直接运行，需手动解除隔离后才能打开（见「关于代码签名」文档）
