v153.3.0-1 最新版本

内核升级：Firefox ESR 153.2 -> ESR 153.3（含 2026-09 安全修复，见 MFSA 2026-93）。

新功能

  • 指纹随机化 (FPP) 开关 — 设置新增「指纹随机化」区：主开关 + 预设 (关闭 / 基础 / 增强 / 自定义) + 细项 (Canvas、WebGL、音频、字体、屏幕、时区) 与隐私窗口；默认关闭
  • DoH 模式与 DNS 供应商选择 — 设置里可选 DoH 模式 (优先回退 / 仅 DoH)，并从下拉选择 DNS 供应商 (含自定义)

修复

  • 视频平台 DOM 全屏四周白边 (Windows) — 修复哔哩哔哩等平台全屏观看视频时，视频四周 (左、右、下) 出现一圈白边 (Nova 窗口留白未清除)
  • QQ / 微信客户端一键登录 — 修复因本地网络访问 (LNA) 拦截导致的快捷登录失效 (新增域名白名单)
  • 偏好设置开关不回显 — 修复 DoH、字体可见性的开关状态不显示、不写入

便携版

  • 配置落在包内 — Windows 便携版改用 -profile 明确指向包内目录，配置不再写到系统盘；Linux 便携版启动器补充 XDG 目录 ( XDG_CONFIG_HOME 等)，避免因用户环境变量导致配置逃逸
  • 包结构精简 — 去掉多余的 bin/ 层级 (Windows / Linux 统一为 vantage/)
  • 修复打包残留 — 修复旧产物残留导致包内文件重复、体积翻倍的问题

发布

  • 内核升级 Firefox ESR 153.3 — 修复多项高危安全漏洞 (内存安全、沙箱逃逸、信息泄露等，详见 Mozilla 安全公告 MFSA 2026-93)
