v153.2.0-2

本版聚焦启动提速与包体积精简，并修复若干体验问题。

新功能

  • 右键「复制为 Markdown 链接」 — 在页面、链接、标签页上右键即可复制为 Markdown：链接 -> [链接文字](URL)，页面 / 标签页 -> [标题](URL)，粘到笔记、文档可用

性能与体积

  • 启动提速 — 采用 LTO + PGO (复用 Mozilla 官方性能数据)，从启动到可上网的时间缩短
  • 包体积精简 — 精简内置语言包 (保留 简中 / 繁中 / 巨硬中文 + 英文 en-US·en-GB·en-CA)
    • Linux tar.xz: 97.3 MB -> 83.5 MB (-14.3%)
    • Windows 安装包: 100.2 MB -> 87.2 MB (-13.0%)；便携版: 162.2 MB -> 132.4 MB (-18.4%)

设置

  • AI 侧栏开关拆分 — 「启用侧栏 AI 聊天」与 「显示侧栏」 拆成两个独立开关；勾选 AI 聊天时会自动显示侧栏并打开 AI 面板

修复

  • Windows 自动更新不再反复弹通知 — 后台检查全程静默，仅在更新成功时提示一次 (此前每次检查都弹)
  • Nova 主题：设置页左栏选中项去掉蓝色指示条 — 保持圆角风格，不再显示左侧蓝色竖条
  • 右键菜单空「AI 聊天」子菜单已清除
  • Linux RPM 安装后在应用菜单里找不到 Vantage — 修复 Fedora / openSUSE 等系统安装 rpm 包后应用菜单不显示的问题 (rpm 包缺少桌面项与图标)；现在安装后会在应用菜单正常显示，可直接点击启动
  • 终端命令 vantage — deb / rpm 安装后新增 vantage 命令，可在终端直接输入 vantage 启动浏览器 (此前只能从菜单或输入完整路径启动)
