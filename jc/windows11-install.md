# Windows 11 安装指南

从制作启动盘到完成系统初始化，一份面向新手的完整 Windows 11 安装教程。

## 安装前准备

- **8GB 或更大** U 盘（制作启动盘用，会清空数据）
- Windows 11 系统镜像（.iso），从微软官网下载：https://www.microsoft.com/zh-cn/software-download/windows11
- 备份原系统的重要文件（桌面、文档、照片等）
- 确认电脑满足 Win11 要求：64 位 CPU、4GB 内存、64GB 硬盘、TPM 2.0

> ⚠️ **TPM 2.0 是什么？** 近几年的电脑基本都支持。老电脑如果不满足，安装时会提示"此电脑无法运行 Windows 11"，解决方法见文末常见问题。

## 第一步：制作启动 U 盘

### 方式一：微软官方工具（最简单）

1. 下载「Windows 11 安装媒体创建工具」并运行
2. 选择语言和版本 → 选择「U 盘」
3. 选择你的 U 盘 → 自动下载并写入，等待完成

### 方式二：Ventoy（推荐，可复用）

```text
1. 下载 Ventoy（https://www.ventoy.net）并安装到 U 盘
2. 把 Win11 的 .iso 文件直接复制进 U 盘
3. 以后想换系统版本，替换 .iso 即可，不用重新制作
```

### 方式三：Rufus（Windows 下老牌工具）

```text
1. 下载 Rufus（https://rufus.ie）
2. 选择 U 盘 → 选择 .iso 镜像 → 点击「开始」
3. 遇到询问保持默认即可
```

## 第二步：从 U 盘启动

1. 插入 U 盘，开机时按启动菜单键（常见：F12 / F8 / F11 / Esc，品牌不同按键不同）
2. 选择 U 盘启动项，进入 Windows 安装程序
3. 选择语言和键盘布局 → 点击「下一步」→「现在安装」

## 第三步：安装系统

1. 输入产品密钥（没有就点「我没有产品密钥」，装完再激活）
2. 选择版本（家庭版/专业版，根据你的密钥选择）
3. 勾选「我接受许可条款」→ 下一步
4. **选择「自定义：仅安装 Windows」**（全新安装）

### 硬盘分区（关键步骤）

| 情况 | 做法 |
|------|------|
| 全新硬盘 | 点「新建」创建分区，系统会自动生成引导分区，剩余空间装系统 |
| 已有分区 | 选原系统分区（C 盘）→ 「格式化」→ 下一步 |
| 想重分区 | 删除所有分区 → 重新「新建」（⚠️ 数据全没，先备份） |

5. 选择目标分区 → 点击「下一步」，系统开始复制文件，期间会自动重启几次，**不要动 U 盘**

## 第四步：初始化设置

重启后进入 OOBE（首次开机设置）：

1. 选择区域（中国）→ 输入法（微软拼音）
2. 连接网络（建议连网，会检查更新）
3. 登录微软账户（或选择「改为域加入」→ 离线账户，跳过登录）
4. 设置 PIN 密码 → 隐私设置全部按需选择 → 等待完成

## 第五步：装完必做

- **激活系统**：设置 → 系统 → 激活，输入密钥或确认数字许可证
- **安装驱动**：Windows 更新里检查可选更新，或到品牌官网下载驱动
- **安装常用软件**：浏览器、输入法、办公软件等
- **开启系统备份**：设置 → 账户 → Windows 备份

## 常见问题

**Q：提示"此电脑无法运行 Windows 11"？**
A：一般是 TPM 或 Secure Boot 未开启。进 BIOS（开机按 Del/F2）→ 开启 TPM（Intel 叫 PTT，AMD 叫 fTPM）→ 开启 Secure Boot → 保存重启。老 CPU 实在不行就装 Windows 10 或改用绕过检测工具（如 Rufus 的扩展选项）。

**Q：安装时找不到硬盘？**
A：进 BIOS 把硬盘模式从 RAID 改成 AHCI（Intel 平台）；或主板未识别 NVMe 固态，更新 BIOS。

**Q：装到一半卡住/报错？**
A：换 USB 2.0 接口重试；重新制作启动盘；检查内存（可单条内存测试）；或检查硬盘健康度（用 PE 里的 DiskGenius/CrystalDiskInfo）。

**Q：不想要新系统里的"预留分区"？**
A：预留分区（EFI/MSR/恢复）是 Windows 正常运行必需的，建议保留，不要手动删除。
