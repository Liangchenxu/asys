系统急救 U 盘制作指南

电脑蓝屏、无法开机、中了木马？系统急救 U 盘就是你的"后悔药"——系统崩溃时用它启动电脑，进入救援环境备份数据、修复系统、查杀病毒。

你需要准备

  • 一个 8GB 或更大 的 U 盘（制作过程会清空 U 盘数据，记得先备份 U 盘里的文件）
  • 一台能正常上网的电脑（用来下载工具）
  • 大约 30 分钟时间

第一步：下载急救工具

推荐组合：Ventoy（启动工具）+ Windows PE 镜像（急救系统）。

  • Ventoy 官网：https://www.ventoy.net
  • PE 镜像：微PE / 优启通等，下载 .iso 格式

💡 为什么用 Ventoy？ 传统方式一个 U 盘只能装一个系统，Ventoy 装一次，以后往 U 盘里直接丢 .iso 文件就能启动，想换 PE 换镜像随时替换，一劳永逸。

第二步：制作启动 U 盘

Windows 下（图形界面）

  1. 解压 Ventoy 压缩包，运行 Ventoy2Disk.exe
  2. 选择你的 U 盘（看清楚盘符，别选错盘！）
  3. 点击「安装」→ 确认提示 → 等待完成
  4. 安装完成后，把下载好的 PE 镜像（.iso）直接复制到 U 盘里

Linux 下（命令行）

# 先确认 U 盘设备名（通常是 /dev/sdX，X 是字母）
lsblk

# 安装 Ventoy 到 U 盘（注意：-i 会清空整个 U 盘！）
sudo sh Ventoy2Disk.sh -i /dev/sdX

第三步：从 U 盘启动电脑

  1. 把 U 盘插到需要急救的电脑上
  2. 开机时狂按启动菜单键（各品牌不同）：
品牌 启动菜单键
华硕 F8 / Esc
联想 F12
戴尔 F12
惠普 F9 / Esc
宏碁 F12
微星 F11
技嘉 F12
  1. 在启动菜单里选择你的 U 盘（带 USB / Ventoy 字样）
  2. 进入 Ventoy 菜单 → 选择 PE 镜像 → 回车

第四步：进入急救环境后做什么

1. 备份重要数据（最优先！）

  • 打开 PE 里的文件管理器
  • 进入原系统盘（通常 C:），把桌面、文档、照片等重要文件复制到移动硬盘或另一个 U 盘
  • ⚠️ 数据无价，先备份再折腾

2. 修复系统引导

  • 使用 PE 自带的「引导修复」工具（如 NTBootAutofix、Dism++）
  • 选择系统盘 → 一键修复 → 重启测试

3. 查杀病毒木马

  • 使用 PE 内置或你放进去的杀毒工具（如火绒、Windows Defender 离线包）
  • 全盘扫描，清理可疑项

4. 实在救不回来 → 重装系统

  • 如果系统损坏严重，直接在 PE 里备份好数据后重装
  • 重装教程见：Windows 11 安装指南

常见问题

Q：制作时提示"安装失败"？ A：换一个 USB 2.0 接口试试；部分 U 盘兼容性差，可尝试 Ventoy 的「安全启动支持」选项后重装。

Q：电脑不支持从 U 盘启动？ A：进 BIOS（开机按 Del/F2）→ 关闭 Secure Boot → 开启 CSM/兼容模式 → 保存重启再试。

Q：PE 进不去，黑屏或卡死？ A：换一个 PE 镜像（兼容性问题）；或检查 U 盘是否为扩容盘（用工具检测真实容量）。

Q：U 盘能恢复成普通 U 盘吗？ A：能。Ventoy 重新安装时选择「升级」可保留数据，选择「安装」会格式化；或者用 Ventoy2Disk.exe 里的「还原空间」功能清空。
