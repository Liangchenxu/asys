隐私声明

本声明说明赛思科技官网（asystech.cn）如何处理您访问和使用本站时产生的信息。

最后更新：2026 年 11 月 28 日

1. 适用范围

本声明适用于 asystech.cn 及其子域（包括主站、Vantage 页面、下载页、搜索起始页和工具箱、文档中心、捐赠页）。

Vantage 浏览器本体的数据处理方式另见 《Vantage 浏览器隐私政策》，不适用本声明。

2. 不收集的信息

  • 本站没有注册、登录、评论或表单提交功能，不收集姓名、手机号、邮箱等个人信息；
  • 不使用 Google Analytics、百度统计等访问统计服务，不进行用户画像或行为分析；
  • 不投放广告，不向第三方出售、出租或共享用户数据；
  • 工具箱中的图片压缩、SVG 转换、哈希计算、文本处理、Base64 转换等操作全部在浏览器本地完成，文件与文本不会上传到服务器。

3. 保存在您设备上的数据

搜索起始页和部分工具会使用浏览器的本地存储（localStorage）记住您的偏好。这些数据只保存在您自己的浏览器里，不会上传到本站服务器，也不属于下文所说的跨境传输：

键名用途
asys_theme_prefs主题、配色、壁纸与搜索框位置等外观偏好
asys_clock_prefs时钟显示项（日期、农历、节气、24 小时制等）
asys_quicklinks您手动添加的快捷链接
asys_bg_library自定义背景图片（以 Data URL 形式保存在本地）
asys_bg_url_cache当天 Bing 壁纸地址缓存
asys_engine上次选择的搜索引擎
asys_tomato / asys_tomato_done番茄钟设置与当日完成数
asys_qr_history二维码工具的本地历史记录

您可以随时通过浏览器的「清除浏览数据」删除这些内容，本站无法读取或恢复它们。

4. 服务器与 CDN 日志（境外处理）

本站是静态站点，页面和文件托管在 GitHub Pages，并通过 Cloudflare 分发，服务器与 CDN 节点位于中国大陆以外。

您打开页面、加载资源或下载文件时，请求会发送到这些境外节点，其中可能包含以下由网络协议自动产生的信息，并由服务商按自身策略记录：

  • IP 地址、浏览器类型与 User-Agent；
  • 请求时间、访问路径、HTTP 状态码与流量信息；
  • 用于区分异常请求的安全标识。

上述访问请求可能构成数据跨境传输。第 3 节所述的本地存储数据始终保存在用户浏览器中，不随访问发送。本站不另行建立访问日志，也不会将服务商日志与用户身份关联，或用于广告和用户画像。日志的保存期限与处理方式由 GitHub 和 Cloudflare 各自的隐私政策决定。

5. Cookie

本站不设置统计或广告 Cookie。Cloudflare 可能为安全防护（如识别自动化请求、应对攻击）设置必要的 Cookie；这类 Cookie 不用于跨站追踪。

6. 第三方请求与外部链接

使用某些功能或点击下载时，您的浏览器会直接向第三方发起请求，这些第三方会按其自身隐私政策处理信息：

  • 搜索起始页：Bing 每日壁纸接口（bing.biturl.top）与图片 CDN（cn.bing.com）；搜索建议来自您当前选择的搜索引擎（百度、Bing、Google、DuckDuckGo、Yandex）。
  • 下载与安装：GitHub Releases、夸克网盘、Microsoft Store，以及本站下载子域 dl.asystech.cn。
  • 驱动与软件下载页：可能跳转到 Intel、AMD、NVIDIA、Realtek 等厂商官网。

我们无法控制第三方的数据处理行为，建议您在使用前查阅对应服务的隐私政策。

7. 未成年人

本站不面向未成年人提供专门服务，也不会主动收集未成年人的个人信息。

8. 您的权利

由于本站不保存您的个人信息，通常不存在需要访问、更正或删除的账户数据。如果您对本声明有疑问，或认为自己的权利受到影响，可以通过下方邮箱联系我们；涉及 GitHub、Cloudflare 等第三方的日志，需要向相应服务商提出请求。

本声明依中华人民共和国法律解释，不影响您依据所在地强制性法律享有的权利。

9. 声明更新

如果本站功能或数据处理方式发生变化，我们会更新本页面并修改顶部的「最后更新」日期。重大变更会在页面上显著提示。

10. 联系我们

隐私相关的问题或建议，请发送邮件至 admin@asystech.cn。
